# Responsive Site Kit — Marketing Site + Matching Email Template

A hand-coded, mobile-first marketing site in semantic HTML, modern CSS, and vanilla JavaScript — plus a matching responsive HTML email template built with table layout and inline CSS, the way production email requires.

## Skills demonstrated
- Semantic HTML5 and accessible markup (landmarks, alt text, focus states)
- Mobile-first CSS with custom properties, grid, and flexbox
- Vanilla JavaScript: mobile navigation, FAQ accordion, scroll reveal
- Responsive HTML email: table layout, inline styles, mobile stacking

## Files
- `index.html`, `styles.css`, `script.js` — the site
- `email-template.html` — matching responsive email template
